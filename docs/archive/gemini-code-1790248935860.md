# Technical Requirement Document (TRD)
## Substation Maintenance AI Chatbot - Technical Architecture & Pipeline Overhaul

### 1. Root Cause Analysis (RCA) & Technical Deficiencies
The deficiency report highlighted critical structural failures in the processing pipeline[cite: 1]:
1. **Pipeline Default Caching**: Hardcoded or cached Transformer IR/PI retrieval filters causing cross-domain query failures[cite: 1].
2. **Dense-Only Retrieval Weakness**: Reliance on standard vector similarity without keyword enforcement (BM25) causing misclassification on domain-specific acronyms (e.g., "CRM", "IR", "PI")[cite: 1].
3. **Ingestion Metadata Loss**: Incomplete document parsing resulting in missing page numbers (`p.None`) and section headers[cite: 1].
4. **Uncalibrated Confidence Metrics**: Confidence calculated from generation likelihood or raw document count rather than query-document semantic alignment[cite: 1].
